# Implementation Guide for Content Writing Agent

## Prerequisites
- Docker & Docker Compose installed
- Python 3.11 (for local development)
- GitHub account for push and pull requests
- API keys for OpenAI (set as OPENAI_API_KEY)
- API keys for Google (set as GOOGLE_API_KEY), optional if using Google Gemini

## Required GitHub Secrets
- OPENAI_API_KEY: Your OpenAI API key
- GOOGLE_API_KEY: Your Google API key (if applicable)

## Environment Variables
- Set the above API keys as environment variables for both local and container environments.

## Local Development Setup
1. Clone the repository
2. Create and activate a Python virtual environment
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Set environment variables:
   ```
   export OPENAI_API_KEY=your_openai_key
   export GOOGLE_API_KEY=your_google_key
   ```
5. Run the app:
   ```
   python app.py
   ```
6. Access the app at http://localhost:5000

## Using Docker
1. Build the Docker image:
   ```
   docker build -t content-agent .
   ```
2. Run the container:
   ```
   docker run -p 5000:5000 -e OPENAI_API_KEY=$OPENAI_API_KEY -e GOOGLE_API_KEY=$GOOGLE_API_KEY content-agent
   ```
3. The app will be accessible at http://localhost:5000

## Using Docker Compose
1. Build and run services:
   ```
   docker-compose up --build
   ```
2. Navigate to http://localhost:5000

## Continuous Integration and Deployment (CI/CD)
- Push changes to the `main` branch or create pull requests.
- GitHub Actions workflow builds the Docker image and can deploy it.
- Customize deployment step in `.github/workflows/cicd.yml` as per your deployment environment.

## Troubleshooting
- Ensure API keys are correctly set as environment variables.
- Check Flask app logs for errors.
- If PDF processing fails, confirm dependencies like poppler for pdfplumber are installed.

## Additional Notes
- The app runs on port 5000.
- For production use, consider setting Flask debug mode to False and configure a production WSGI server.
- Customize environment variables and services as needed.
